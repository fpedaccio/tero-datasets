# Tero: datasets

Este repositorio publica los datasets que generó el Proyecto Final de Ingeniería *Tero*, un sistema de detección de fraude por correo electrónico para pymes argentinas.

| Carpeta | Qué contiene |
|---|---|
| [`correos_sinteticos/`](correos_sinteticos/) | Buzón sintético de 3.215 correos y 24 escenarios etiquetados (18 de fraude y 6 legítimos), junto con el código que lo genera. Con este buzón se evaluó el motor de detección completo. |

## Dataset externo utilizado

El modelo de lenguaje (BETO) se entrenó con **SpaPhish**, un dataset de correos de phishing en español publicado en Mendeley Data con licencia CC BY 4.0. Se usó la versión 4 y no se redistribuye en este repositorio.

## Datos que no se publican

El correo real de las casillas que se conectaron durante las pruebas no se publica.
